## <img src="https://media.giphy.com/media/WUlplcMpOCEmTGBtBW/giphy.gif" width="30"> &nbsp;About Me

<img align="right" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" width="320" alt="Coding GIF"/>

<br/>

I'm a **Computer Science Engineering** student who enjoys building **scalable web applications, backend systems, and cloud infrastructure**.

I work mainly with **JavaScript, Node.js, React, MongoDB, PostgreSQL, Docker, AWS, and CI/CD**, and I'm currently going deeper into **Cloud Engineering, Kubernetes, Infrastructure as Code, and DevOps**.

I like turning ideas into working systems — from writing APIs and database logic to containerizing applications and deploying them to the cloud.

<br/>

- 🔨 Building **full-stack web applications** and **REST APIs**
- ☁️ Deploying applications on **AWS**
- 🐳 Containerizing apps with **Docker** & orchestrating with **Kubernetes**
- 🔄 Building **CI/CD pipelines** with GitHub Actions & Jenkins
- 🏗️ Exploring **Infrastructure as Code** with Terraform
- 🔐 Implementing **production-ready backend practices**
- 🌱 Currently focused on **Cloud & DevOps**
